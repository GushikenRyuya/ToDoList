# ふたりのタスク

ブラウザで開いて、ふたりで同時に編集できるタスク管理アプリです。

- リスト(タイトル)の中に、タスクを並べる
- タスクは「チェックボックス・タスク内容・備考」
- 変更は相手の画面にリアルタイムで反映
- ファイルは静的ページのみ(GitHub Pages で公開)。データ保存は Firebase Firestore(無料枠で十分)

## ファイル構成

| ファイル | 役割 |
|---|---|
| `index.html` | アプリ本体 |
| `firebase-config.js` | Firebase の接続設定(自分の値に書き換える) |
| `firestore.rules` | Firestore のルール(コンソールに貼り付ける) |

## セットアップ(初回のみ・約10分)

### 1. Firebase でデータ置き場を作る
1. https://console.firebase.google.com/ でプロジェクトを作成(Analytics は不要)
2. 左メニュー「構築 > Firestore Database」→「データベースを作成」→ 本番モードで開始、ロケーションは `asia-northeast1`(東京)
3. 「ルール」タブに `firestore.rules` の中身を貼り付けて「公開」
4. 歯車アイコン「プロジェクトの設定」→「マイアプリ」→ ウェブ(`</>`)を追加 → 表示される `firebaseConfig` の値を `firebase-config.js` にコピー

### 2. GitHub Pages で公開する
1. GitHub で新しいリポジトリを作り、このフォルダの3ファイルをアップロード
2. リポジトリの「Settings > Pages」→ Source を `Deploy from a branch`、Branch を `main` / `/ (root)` にして Save
3. 数分後に `https://<ユーザー名>.github.io/<リポジトリ名>/` で開ける

### 3. ふたりで使い始める
1. 公開URLを彼女に送り、お互いのスマホ・PCで開く(合言葉の入力はありません)
2. スマホならホーム画面に追加すると、アプリのように使える

## 無料枠と制限(2026年11月時点の公式情報)

- **Firestore(無料枠)**: 保存1 GiB、読み取り5万回/日、書き込み2万回/日、削除2万回/日。期限はなく、ふたりのタスク管理なら十分収まります。超えた分は課金プランへ切り替えた場合のみ課金され、切り替えなければ上限に達した時点で一時的に使えなくなるだけです。
- **GitHub Pages**: 公開サイトは1 GBまで、月100 GBの帯域(目安)。無料プランでは公開リポジトリのみ対応です。

## 注意

- 無料の GitHub では、リポジトリを非公開にしても Pages のサイトは公開できません(非公開で公開するには Enterprise Cloud が必要)。URLを知っている人はだれでも開けて、編集もできます。
- URLは他人に教えない・SNSに載せないでください。
- 心配な場合は、Firebase Authentication(Googleログイン)を追加し、ルールを「ふたりのメールアドレスのみ許可」に変更できます。
